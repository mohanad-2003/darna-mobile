# Prompts for the next illustrations

Same style as the onboarding and empty-state art, so the app stays one family.
Save each result as PNG in `design/source/` with the file name given, then tell me:
I convert them to light WebP and wire them in.

## Shared style block (put at the start of every prompt)

```
Premium minimal editorial 3D clay illustration for Darna, an Arabic Palestinian real estate
mobile app. Matte ceramic surfaces, rounded architectural forms, soft ambient studio shadows.
Palette strictly deep teal #0F766E, pale mint #DBEEE8, warm ivory #FAF6F1, muted sandstone
#DCC6A3, restrained charcoal. Warm Levantine limestone architecture, arched doorways, tasteful
olive foliage. Square 1024x1024, one centered isolated scene, 12% clear margin on all sides,
flat warm ivory background exactly #FAF6F1 (no gradient, no vignette). No text, letters,
numbers, logos, watermarks, UI text, phone mockups, people or hands.
```
